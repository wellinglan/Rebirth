# Rebirth Document Registry

> Classification: **Active documentation governance**
> Current product, protocol, version, Gate, and deployment facts are owned by
> [Current Baseline](CURRENT_BASELINE.md). Historical documents remain evidence
> of their recorded Sprint and do not override that baseline.

## Reading Order

1. [Current Baseline](CURRENT_BASELINE.md) for the current code and acceptance
   state.
2. [Manual Acceptance Registry](manual_tests/README.md) for current Gate
   conclusions and evidence succession.
3. [Release Readiness](RELEASE_READINESS.md) for private-Alpha and public-release
   blockers.
4. The feature or Sprint document for design rationale and historical scope.

## Maintenance Rule

version, Gate, or deployment claims into a historical appendix. Historical
files are not renamed merely to normalize numbering.
